   # IIST Open Source Society

   Open-source projects by and for students of IIST.

   - **[ClubOrbit](https://github.com/iist-oss/club-orbit)**: one orbit for everything your club does. Certificates, registration forms, bulk mail and short links on GitHub Pages and Supabase.
   - **[iist-oss-website](https://github.com/iist-oss/iist-oss-website)**: the society's website.

   Want to contribute? Open an issue or a pull request in any repository.
